SELECT id, feedback_text, sentiment, tags,

- STORE-04 error isolation: Wrap entire function body in try/catch. On error: `console.error("[feedback-vector-store] searchSimilarFeedback error:", error)` then `return []`. Never throw -- return empty array so callers proceed without feedback.
